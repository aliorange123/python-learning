# python-learning

我的 Python 学习记录。从零开始，每天一课。

## 这是什么

跟着《LLM 应用实习路线图》的阶段 0 走，把每节课的练习代码放在这里。

**不追求代码漂亮，追求关掉资料能自己写出来。**

## 目录

| 文件 / 目录 | 内容 |
|---|---|
| **`笔记.md`** | ⭐ **我自己的学习笔记** —— 踩坑清单、C 与 Python 的差异、我原本想错的地方、自测题。**复习看这个** |
| `lessons/` | 每节课的练习代码，按课号命名 |
| `projects/` | 阶段性的小项目 |

## 怎么跑

```powershell
python lessons\01_hello.py
```
